PROJECTS & IMPACT

Selected delivery outcomes from production work.

Vault Token Rotation Automation

When 53 client Vault tokens were due to expire, I replaced a manual edit-everything process with Bash, kubectl, and jq scripts. One script finds the namespaces using the old token. The other runs in dry-run mode first, then replaces the token in Deployments and ConfigMaps and restarts them.

  • About 2 hours of manual edits per large client reduced to under 1 minute
  • No manual replacement mistakes across clients with up to 50 tenants
  • Now reused by the team to find client namespaces during deployments

Jenkins Agent Connectivity at Scale

Verified Jenkins connectivity on 226 Windows EC2 servers. A PowerShell script removed the repeated RDP login steps, and a second script checked the Java version and agent.jar connection on each server.

  • Replaced an estimated 10-12 days of manual effort
  • Login reduced to the server IP and credentials
